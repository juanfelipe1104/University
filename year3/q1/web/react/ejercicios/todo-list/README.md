# ToDo List

Lista de tareas desarrollada con React. Permite crear, completar y eliminar tareas.

## Ejecución

```console
npm install
npm run dev
```

## Estructura

- `App.jsx`: compone la cabecera y la aplicación.
- `Logo.jsx`: componente reutilizable del logotipo textual.
- `FormToDo.jsx`: controla el input y crea tareas con identificadores únicos.
- `ListToDo.jsx`: mantiene el estado y define las operaciones sobre la lista.
- `ToDo.jsx`: representa una tarea individual.
